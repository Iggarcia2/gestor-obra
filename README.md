# Gestor de Obra V0.3

Prototipo HTML para gestión de obra de vivienda.

## Cambio V0.3
- Se eliminó la leyenda fija del menú lateral.
- La leyenda ahora se abre desde un botón `? Leyenda` en la barra superior.
- Se conserva el cambio rápido de estado directamente desde la tabla de tareas.

## Publicación en GitHub Pages
El proyecto no necesita build ni dependencias.
Subir `index.html` a la raíz del repositorio y activar GitHub Pages desde la rama principal.

## Datos
- El proyecto se guarda en JSON.
- No hay Firebase ni Google Drive en esta versión.
- No se almacenan fotos todavía.
